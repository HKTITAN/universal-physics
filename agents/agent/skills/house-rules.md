# House Rules (binding for every agent on this team)

These rules are the distilled discipline of the universal-physics program — 23
adversarially-refereed iterations. Violating them voids your output.

## Epistemic tags (mandatory on every load-bearing claim)

- `[ESTABLISHED]` — proven, textbook, or live-verified against a primary source.
- `[INFERENCE, high|medium|low]` — your reasoning from established facts. State the chain.
- `[SPECULATIVE]` — motivated guess. Never dress it as more.
- `[OPEN]` — genuinely unknown. The most valuable tag when honest.
- `[CONTESTED]` — live disagreement in the literature; cite both sides.

**The cardinal rule: speculation never wears the clothes of established fact.**

## The anti-crank protocol

1. A construction that installs its answer is a **failure**, not a result. Always
   audit: what exactly is input, what is output, where does the target datum
   (signature, causal order, eigenvalue…) first appear?
2. Cite only real, checkable sources. Verify every post-1990 citation **live**
   (fetch the arXiv abstract or journal page; quote a verbatim anchor). If you
   cannot verify, tag `[unverified]` — never fabricate a title, quote, volume,
   or theorem number.
3. Pre-arXiv canonical results (Tomita–Takesaki, Bisognano–Wichmann, Connes,
   Kato, Birkhoff…) may be cited without live verification but must be named
   precisely.
4. **Counters are sacred.** Iteration N with an unchanged verdict is the
   (N−1)-th consecutive confirmation. Recount yourself; never trust an upstream
   counter (a workflow synthesis has miscounted before and was corrected).
5. **Retraction on contradiction.** If two established results conflict, one is
   wrong: find it, strike it publicly (dated addendum, never silent deletion),
   and record the strike in the changelog. Struck claims are documented history.
6. Negative results, failed probes, and methods-no-gos are first-class results.
   Document wrong turns; they are the map's edges.

## Submission discipline

- Everything you produce is a **submission** until a referee with default
  stance REFUTE has re-derived it cold. Write proofs so a specialist can check
  them without you in the room.
- Grade honestly *downward* under uncertainty. The program's credibility is its
  only asset.

## Memory protocol

Before starting work: search the **shared memory** (`containerTag: up-shared`)
for the current campaign state and your **private memory**
(`up-agent-<yourname>`) for your own working notes. After finishing: write one
concise memory to your private tag (what you did, what failed, what's next) and
— only if you produced a refereed, integrated result — one to the shared tag.
Shared memory records *state*, not drafts.
